    The Example

    You receive scores in the same way, regardless of the course model.

    Weights Are Applied

    CO Model

    Assignment scores are multiplied according to the associated assignment weight. An application of an LO in a 1× class poll will have half as much impact as an application in a 2× assignment.

    Weighted Average

    Grades are a weighted average. Each bin accounts for a scaling factor of the weighted average.

    Assessment Type Model

    Assignment bins will be fixed once you receive those scores, so that share of the weighted average is stable.

    CO Model

    CO bins continue to be filled up all semester, so no share of the weighted average is fixed until the semester finishes.

    Assignments Still to Come

    If you have not yet received a score in a bin, that bin is removed completely. This is implemented in the calculations by dividing a student's results so far by the share of the class they have completed.
